# Molecules

Place for combined components (SearchBar, FormField, etc.).
Compounded from atoms and primitives.

## Componentes

| Componente | Descripción |
|------------|-------------|
| SearchInput | Campo de búsqueda con icono y botón limpiar |
| DateRangeFilters | Filtros de rango de fechas (desde/hasta) |
| EmptyState | Estado vacío para listas |
| ErrorState | Estado de error con retry |
| PageHeader | Cabecera de página con título, descripción y acciones |
| FormSection | Sección de formulario con label |
| ConfirmDialog | Diálogo de confirmación |
| BreadcrumbNav | Navegación por migas |
| ListItemSkeleton | Skeleton para ítems de lista (avatar + líneas) |
| TableSkeleton | Skeleton para tablas |
| PhoneInputWithCountry | Input de teléfono con selector de país |
